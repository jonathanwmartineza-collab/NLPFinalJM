# One-shot prompt library

Twelve copy-paste prompts, one per app type, all using the same skeleton: ROLE · GOAL · AUDIENCE · CONTENT & FEATURES · DESIGN DIRECTION · TECH CONSTRAINTS · ACCESSIBILITY & PERFORMANCE BAR · DELIVERABLE FORMAT · SELF-CHECK.

| Prompt | Category | Lead agent | Where to run |
|---|---|---|---|
| [Landing page](landing-page.md) | Marketing | brand-director | One-shot Studio or Claude Code |
| [SaaS analytics dashboard](saas-dashboard.md) | Product | ux-architect | One-shot Studio or Claude Code |
| [E-commerce storefront](ecommerce-storefront.md) | Commerce | ui-designer | One-shot Studio or Claude Code |
| [Personal portfolio](portfolio.md) | Marketing | ui-designer | One-shot Studio or Claude Code |
| [Internal tool (CRUD)](internal-tool-crud.md) | Product | frontend-engineer | One-shot Studio or Claude Code |
| [Mobile-first PWA](pwa-mobile-app.md) | Mobile | mobile-engineer | Claude Code (multi-file) |
| [AI chat app](ai-chat-app.md) | AI | ai-engineer | Claude Code (multi-file) |
| [Data-viz explorer](data-viz-explorer.md) | Data | data-engineer | One-shot Studio or Claude Code |
| [Browser game](browser-game.md) | Games | creative-technologist | One-shot Studio or Claude Code |
| [Chrome extension](chrome-extension.md) | Tools | frontend-engineer | Claude Code (multi-file) |
| [REST API with docs page](rest-api-docs.md) | Backend | backend-engineer | Claude Code (multi-file) |
| [Design-system starter](design-system-starter.md) | Design | design-systems-lead | One-shot Studio or Claude Code |

The website reads `library.json`. Edit prompts here, then run `npm run build`.
