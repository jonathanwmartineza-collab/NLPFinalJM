# 03 · UX/UI standards the team follows

Full notes (with sources) live in the knowledge shelf; this is the index.
- **Accessibility:** WCAG 2.2 AA, including the 2.2 additions (2.4.11, 2.5.7, 2.5.8, 3.2.6, 3.3.7, 3.3.8) → knowledge/_shared/wcag-22-essentials.md
- **Usability:** Nielsen's 10 heuristics and the Laws of UX (Fitts, Hick, Jakob, Miller, Doherty, peak-end) → knowledge/_shared/ux-heuristics-and-laws.md
- **Platform guidance:** Apple Human Interface Guidelines (clarity, deference, depth; native patterns) — https://developer.apple.com/design/human-interface-guidelines/ ; Material Design 3 (dynamic colour, tokens, components, accessibility) — https://m3.material.io/ (accessed 2026-11-21)
- **Tokens and theming:** W3C Design Tokens format, semantic tokens, dark mode remapping, contrast records → knowledge/_shared/design-tokens-and-theming.md
- **Performance:** Core Web Vitals thresholds (LCP ≤ 2.5 s, INP ≤ 200 ms, CLS ≤ 0.1) and budgets → knowledge/_shared/core-web-vitals.md
- **Responsive:** design from 360px up; `minmax(0,1fr)` grids; no horizontal scroll at 320px (WCAG 1.4.10).
