# Expert roster

Generated by `node scripts/gen-docs.mjs` from `.claude/agents`. The agent files are the source of truth.

## Changes from the kit's baseline
- Added **growth-analyst** (Lucas) and **privacy-compliance** (Amara): needed to launch real products (measurement; privacy, consent, AI disclosure).
- **performance-seo-engineer** and **technical-writer** run on Sonnet (diagnosis and writing need more judgement than Haiku).
- **creative-technologist** also covers game development.
- Haiku is used by the website for fast routing and the economy cost mode.

## Lanes between roles that could overlap
- Orchestrator routes and synthesises; Delivery Lead runs milestones and status.
- Brand Director decides what the brand is and says; UI Designer decides how screens look; Design Systems Lead owns reusable tokens and components.
- Meta Agent writes agents and skills; Knowledge Curator writes knowledge notes.
- Security Engineer handles attacks and controls; Privacy & Compliance handles data rights, consent, notices, licences and AI disclosure.
