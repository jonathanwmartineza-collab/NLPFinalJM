# 01 · Roles in a full-lifecycle product studio

How top digital product studios staff an app from idea to launch, and which BrainyApp agent covers each role. Summarised from common industry practice and the standards each role follows (sources at the end).

| Role | Responsibilities | Key deliverables | Quality bar / standards | Agent |
|---|---|---|---|---|
| Studio director / orchestrator | Scope, routing, synthesis, final call | Plan, combined answers | Parallel work, red-team gate | Nova (orchestrator) |
| Delivery lead / technical PM | Milestones, owners, risks, status | Plan, risk log, status | Definition of done with evidence | Owen (delivery-lead) |
| Product strategist / PM | Problem, users, scope, priorities | PRD, user stories, metrics | Testable acceptance criteria | Maya (product-strategist) |
| UX researcher | Evidence about users | Personas, JTBD, journeys, test scripts | Evidence vs assumption labelled | Ravi (ux-researcher) |
| Growth / analytics | Measurement, funnels, experiments | Metrics plan, tracking plan, experiments | Privacy-friendly, pre-registered | Lucas (growth-analyst) |
| UX architect / interaction designer | IA, flows, states, wireframes | Flows, state inventory, wireframes | Nielsen heuristics, every state | Iris (ux-architect) |
| UI / visual designer | Look and feel | Screens, visual direction | Hierarchy, contrast, polish | Kai (ui-designer) |
| Design systems lead | Tokens, components, theming | Token JSON/CSS, component specs | W3C tokens, WCAG contrast | Lena (design-systems-lead) |
| Content designer / UX writer | Words in the interface | Voice guide, microcopy | Plain language, helpful errors | Jonah (content-designer) |
| Accessibility specialist | Inclusive design and audits | WCAG 2.2 audits, fixes | WCAG 2.2 AA | Noor (accessibility-specialist) |
| Motion designer | Purposeful motion | Motion specs | Reduced-motion support | Sasha (motion-designer) |
| Brand / creative director | Positioning, identity, story | Brand brief, logo concept, landing narrative | Distinctive, original | Valentina (brand-director) |
| Software architect / tech lead | Stack, architecture, decisions | ADRs, diagrams | Boring tech, verified limits | Marco (software-architect) |
| Front-end engineer | UI implementation | Components, pages, one-shot builds | Semantic HTML, a11y, Web Vitals | Zara (frontend-engineer) |
| Back-end / API engineer | APIs, functions, auth | Endpoints, schemas, tests | Validation, error shape, limits | Diego (backend-engineer) |
| Mobile engineer | PWA and native | Installable apps, offline | Touch-first, offline honesty | Hana (mobile-engineer) |
| AI / LLM engineer | Model features | Streaming, caching, evals, guards | OWASP LLM Top 10, budgets | Quinn (ai-engineer) |
| Data engineer | Schemas, storage, pipelines | Models, migrations | Correctness over time | Felix (data-engineer) |
| Creative technologist / game dev | Games, canvas, generative | Playable builds | 60 fps, fixed timestep | Juno (creative-technologist) |
| Prompt engineer | One-shot and system prompts | Prompt library, evals | Measurable prompt quality | Sage (prompt-engineer) |
| QA / test automation | Proof that it works | Test plans, Vitest, Playwright | Evidence rule | Ivy (qa-engineer) |
| Application security | Threats and controls | Threat model, reviews | OWASP Top 10 + LLM Top 10 | Rhea (security-engineer) |
| Performance & SEO | Speed and findability | Budgets, Lighthouse, metadata | Core Web Vitals | Arjun (performance-seo-engineer) |
| DevOps / platform | Deploys and runtime | netlify.toml, functions, env | Read the deploy log | Tess (devops-engineer) |
| Technical writer | Docs people can follow | README, guides, resources | Plain language, dated facts | Milo (technical-writer) |
| Privacy & compliance | Data rights and disclosures | Privacy notes, checklists | GDPR/CCPA basics; not legal advice | Amara (privacy-compliance) |
| Independent reviewer | Red team | Scored reviews, release gate | Blockers vs notes | Morgan (red-team-reviewer) |
| Team builder / knowledge | Agents, skills, knowledge | Agent files, skills, notes | Validators pass; sourced notes | Orion (meta-agent), Elise (knowledge-curator) |

**Coverage check:** the roster covers discovery → design → build → quality → launch → operations. Gaps deliberately left for later: native store release management and paid marketing; add them with the meta agent when needed.

Sources: https://www.nngroup.com/articles/ (UX roles and methods), https://www.w3.org/TR/WCAG22/ , https://owasp.org/www-project-top-10-for-large-language-model-applications/ , https://web.dev/articles/vitals (all accessed 2026-11-21).
