# How to talk to your team

**In Claude Code (this repository):**
- One expert: `@agent-ui-designer Give the pricing page a clearer hierarchy.`
- The team: `@agent-orchestrator Should our app use Supabase or Netlify Blobs for user data?`
- Big builds: "You (the main session) act as the orchestrator in .claude/agents/orchestrator.md; delegate with the Agent tool. Build …"
- Long session: `/handoff`. Fuzzy idea: `/grill-me`.

**On the website:** pick an expert in the sidebar, or "Ask the whole team"; use the One-shot Studio for a complete single-page app; copy prompts from the Library into Claude Code.

**Five example prompts**
1. "@agent-product-strategist Write a PRD for a habit tracker for night-shift nurses."
2. "@agent-orchestrator Plan v1 of a booking app for independent yoga teachers: scope, UX, stack, risks."
3. "@agent-accessibility-specialist Audit web/src/pages/StudioPage.tsx against WCAG 2.2 AA."
4. "@agent-creative-technologist Build a one-file endless-runner game with touch controls."
5. "@agent-security-engineer Review netlify/lib/handler.ts for cost-abuse and injection risks."
