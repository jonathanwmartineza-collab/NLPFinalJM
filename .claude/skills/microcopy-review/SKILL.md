# Microcopy review

## Procedure
1. Inventory every string on the screen: headings, labels, placeholders, buttons, helper text, errors, empty states, toasts.
2. Buttons: verb + object ("Download page", not "OK"); destructive actions name the consequence.
3. Labels: visible, persistent (placeholders are not labels); say what is needed and the format.
4. Errors: what happened + how to fix it, next to the field, announced to screen readers; never blame ("That email is missing an @").
5. Empty states: what this is, why it's empty, one action to start.
6. Confirmations: state the result and offer undo where possible.
7. Cut every word that doesn't help the user decide or act.

## Checklist
- [ ] No vague buttons (OK, Submit, Click here).
- [ ] Every error explains the fix.
- [ ] Every empty state has a next action.
- [ ] Link text makes sense out of context.
