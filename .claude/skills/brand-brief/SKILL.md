# Brand brief

## Procedure
1. Positioning statement: For [audience] who [need], [brand] is the [category] that [key benefit], unlike [alternative].
2. Personality: 3–4 traits, each with "is / is not".
3. Naming (if needed): 8–12 options across descriptive, evocative and invented; check pronounceability and obvious conflicts; shortlist 3 with rationale. Remind the owner to check trademarks and domains.
4. Visual direction: palette (dominant, support, accent with contrast notes), type pairing (headline + body, free fonts), imagery style, shape language. Avoid look-alikes of known brands.
5. Logo concept: a simple, original SVG mark + wordmark idea, readable at 16px.
6. Landing story: headline, subhead, 3 proof points, primary CTA, objection handling.

## Checklist
- [ ] Positioning names a real alternative.
- [ ] Palette passes contrast for text uses.
- [ ] Nothing imitates an existing brand's name, mark or distinctive visuals.
