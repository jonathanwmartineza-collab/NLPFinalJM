# ADR writer

## Procedure
1. Number the ADR (docs/adr/NNNN-title.md). One decision per ADR.
2. Context: forces and constraints, including platform limits verified in official docs today (cite URL + date).
3. Options: 2–4, each with pros/cons and cost.
4. Decision: what we chose, in one sentence.
5. Consequences: what becomes easier, harder, and what we must monitor.
6. Status: proposed / accepted / superseded by NNNN.

## Checklist
- [ ] Limits and prices cite a source and date.
- [ ] Rejected options are recorded with reasons.
- [ ] Consequences include risks and follow-ups.

## Output template
# NNNN. Title
Status · Date · Context · Options · Decision · Consequences · Sources
